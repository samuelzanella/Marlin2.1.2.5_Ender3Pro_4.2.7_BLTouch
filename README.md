# Ender 3 Pro Marlin firmware

This repository contains the code required to modify and compile the firmware for an Ender 3 Pro printer with board version 4.2.7 and BLTouch installed.

The code consists of Marlin (https://github.com/MarlinFirmware/Marlin/tree/lts-2.1.2) and Configuration repositories (https://github.com/MarlinFirmware/Configurations/tree/release-2.1.2.5).

Customized configuration for this printer -based on Configuration repository- is placed inside Marlin/ folder, ready to be compiled.

The firmware compiled with this code is also present in the main folder.
